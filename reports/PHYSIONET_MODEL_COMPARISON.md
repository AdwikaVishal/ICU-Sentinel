## 6. Limitations

1. **Subset of data:** Results on 974/39,810 patients (2.4%) with complete features
2. **Missing EtCO2/TroponinI:** Features with 100% missingness excluded
3. **No test set:** PhysioNet test set requires credentialed access
4. **Single split:** No cross-validation; bootstrap CIs from single test split
5. **Class imbalance:** 1.35% positive rate in test set
